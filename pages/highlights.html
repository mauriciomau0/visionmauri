Computer vision in biomechanics

Gait Classification Using 2D Pose Estimation and Explainable AI

Can smartphone video distinguish healthy older adults from people with transfemoral amputation? This project used single-camera walking videos to classify gait patterns and identify clinically meaningful asymmetries.

A Random Forest model reached 96.2% accuracy, with SHAP explaining which variables contributed most to each prediction. The model’s assumptions and limitations were documented clearly.

Research highlights

  • Clinically meaningful asymmetry measures used for classification
  • 100% precision and 92% recall for amputee detection
  • Three confidence zones: Green, Yellow, and Red
  • SHAP plots for each participant
  • Stride speed asymmetry identified as the strongest predictor
  • Data assumptions and single-camera limitations documented under Pillar 1 of the RCAI framework

Population: Older adults (n=13) and transfemoral amputees (n=3)

Computer vision in health

Gait Stability Prediction Using Computer Vision and Synthetic Data

Can computer vision help predict gait stability in older adults? This project explored an accessible approach to fall risk monitoring using walking videos and synthetic data.

The study showed that synthetic data could preserve key biomechanical relationships and support accurate margin of stability prediction. Models trained only on synthetic data outperformed models trained on real data alone.

Research highlights

  • Gait stability assessment in older adults using computer vision and synthetic data
  • 97.09% overall synthetic data fidelity
  • Synthetic data preserved biomechanical variable relationships
  • Synthetic-data-trained models outperformed real-data-only models

Population: older adults (n = 14)

Synthetic data

Synthetic Data-Driven Machine Learning for Performance Prediction

Can synthetic data help improve athlete performance prediction when real datasets are limited? This project explored synthetic data generation as a strategy to address data scarcity in athlete monitoring.

The study showed that synthetic data could preserve key patterns in the original dataset and improve model performance across multiple prediction tasks.

Research highlights

  • Synthetic data used to support athlete performance prediction
  • Synthetic data preserved relevant statistical relationships
  • Models using synthetic data outperformed real-data baselines
  • Optimal synthetic data proportions identified for each prediction task

Dataset: athlete performance dataset (n = 41)

Machine learning in monitoring

Machine Learning-Based Performance Monitoring for Athletes

Can machine learning help predict performance decline in athletes after competition? This project investigated performance attenuation in Gaelic football players by analyzing changes before and after a match.

The study showed that machine learning models could predict performance rankings with high accuracy, reaching F1-scores of up to 0.90.

Research highlights

  • Machine learning used to monitor performance attenuation in Gaelic football athletes
  • Performance decline assessed through pre- and post-match changes
  • High predictive accuracy across multiple performance rankings
  • Best models reached F1-scores of up to 0.90

Sport: Gaelic Football

Dataset: athletes (n = 41)

Machine learning in public health

Fall Detection System for Public Health

My team and I developed a machine learning framework to detect falls in older adults using low-cost inertial sensors. The project addressed a major public health issue in Brazil, where falls are a leading cause of injury, hospitalization, and healthcare costs among older adults.

The system detected fall patterns with 99.4% accuracy and was designed to support real-time intervention.

Research highlights

  • Developed a wearable fall detection system using inertial sensors
  • Applied machine learning to classify fall patterns
  • Achieved 99.4% accuracy with k-Nearest Neighbor algorithms
  • Validated the system with real participants
  • Designed the solution to support faster intervention
